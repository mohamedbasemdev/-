# مشروع موقع المأذون الشرعي | Marriage Officiant Project

[English Version Below]

## 📝 وصف المشروع
موقع تعريفي احترافي مصمم خصيصاً للمأذون الشرعي الشيخ خالد العمار. يوفر الموقع واجهة سهلة للمستخدمين للوصول إلى خدمات وزارة العدل السعودية (ناجز) وتوثيق عقود النكاح، مع مراعاة كاملة لقواعد تحسين محركات البحث (SEO).

### ✨ المميزات:
- **Responsive:** متوافق تماماً مع الجوال والأجهزة اللوحية.
- **SEO Ready:** يتضمن وسوم Canonical و Meta Tags احترافية.
- **Dark/Light Blur Effects:** استخدام تأثيرات Blur و Glassmorphism في التصميم.
- **Integration:** ربط مباشر مع Firebase وخدمات ناجز.

---

## 📝 Project Description
A professional landing page developed for a Marriage Officiant (Sheikh Khalid Al-Ammar). The website facilitates access to Saudi Ministry of Justice services (Najiz) and provides a seamless user experience for marriage contract procedures.

### ✨ Key Features:
- **Fully Responsive:** Optimized for all screen sizes.
- **SEO Optimized:** Implements Canonical tags and high-ranking keywords.
- **Performance:** Lightweight code with fast loading times.
- **Gov Services Integration:** Direct links to official Saudi portals.
